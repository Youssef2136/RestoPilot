# RestoPilot

RestoPilot is a multi-tenant SaaS **Order Collection Layer** for restaurants:
customers browse a menu and submit orders without creating an account, while
restaurant staff manage those orders through operational dashboards. It is
explicitly **not a POS** — the external POS remains responsible for payment
collection, accounting, printing, and internal inventory.
